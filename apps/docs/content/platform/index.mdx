## What is Forge?

Forge turns a plain-language description into a working web application. Describe what you need — a booking widget, an occupancy dashboard, a member-facing page — and Forge scaffolds the project, shows you a live preview, and deploys it to TRA infrastructure.

It is built and maintained by the TRA tech team for internal use. Sign-in is via your TRA GitHub account at [forge.tmidev.net](https://forge.tmidev.net).

## What can you build?

- **Guest-facing pages** — reservation forms, activity schedules, resort information pages
- **Operations tools** — dashboards, trackers, and internal utilities
- **Member experiences** — portal pages, referral forms, tour-booking flows

Every project is a real React + TypeScript + Tailwind codebase. You can hand-edit the generated code in the built-in editor, connect it to a GitHub repository, and deploy it with one click.

## Getting started

1. Sign in at [forge.tmidev.net](https://forge.tmidev.net) with GitHub
2. Describe what you want to build in the prompt box
3. Iterate in the workspace — chat with the AI, preview changes live, edit code directly
4. Deploy from the workspace when you're ready

Read the [Quickstart](/platform/quickstart) for a full walkthrough, or the [User Guide](/platform/usingforge/deploy) for deployment details.
